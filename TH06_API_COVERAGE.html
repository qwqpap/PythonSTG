TH06 引擎 API 覆盖清单 ​

本文件是机制对照，不是另一份 TODO；实施顺序和唯一状态记录仍在 EDITOR_IMPLEMENTATION_TODO.md。

目标是用普通 Python 内容脚本表达六关和 Extra，不是引入 ECL VM，也不是声称素材、关卡 内容和像素表现已经复刻。参考源码： YomotsuHisami/th06，核对提交 fa4d48f66d4701fef6c5e802ca85a738b0d5177c。这是从此前 eagler-touhou 调查延续的 TH06 checkout；不能把其源码指令清单当成原作全部 ECL 文件已执行。

1. 支持与验收怎么区分 ​

  • 可表达：普通内容 API 能组合出机制，不需要改 Pool 私有状态或逐弹回调。
  • 已实跑：指定数学、时序或真实 Runtime 路径实际运行通过；不是全部关卡通过。
  • 缺口：仍缺接口、正式接线或规则可配置性。
  • 未验收：缺原作脚本/资源、真实呈现或独立对照，不能算完成。

接口覆盖、生成器覆盖、纯 GUI 可编辑性、完整内容、像素一致性是五件不同的事。本轮不改 GUI； 新增高级规则走 Runtime/RawPython，不把它们写成已经有对应拖拽节点。

4. 性能与验证边界 ​

  • 大量子弹仍在现有结构化数组/Numba 内核；不把 50k Bullet 变成 50k FrameTask。
  • actor/事件/Boss 规则是稀疏控制。48/100 Laser 更新与碰撞单独测量，不借弹池数值宣称激光性能。
  • JIT 冷编译、预热后 CPU 更新、GL 提交/实际 GPU 呈现分别记录；Rust 不进入本轮。
  • 独立符卡预览拥有正式 Pool/Context/EventBus；成功重启会替换全部池。渲染必须读当前池， 不能继续读调用者最初传入的旧池。候选 bind/start 发射只影响候选；失败保留旧实例。
  • 时停不调用 renderer 当作游戏时钟。主循环按 mask 暂停相关 update，actor 任务继续； Boss elapsed timer 独立暂停/重置，不倒退任务时钟/Trace。 effects 域暂停粒子池和 emoji 系统，不是全部 GUI/装饰动画。
  • 当前即时 Runtime/生成子进程/Native/Performance 结果统一记 TODO。本清单不借旧测试 计数证明新代码，也不宣称 maintainer/new-user Usability 已通过。
  • 独立工具绘制真实激光/道具/粒子与当前弹池；转换敌人仍是位置标记，缺完整玩家流程。真正的 PySide6 嵌入与整关输入链本批 not run，GL 压力帧不能替代它们。

5. 尚未关闭的主要缺口 ​

  1. 原作六关/Extra、每难度、四机体的实际 ECL/资源内容移植与整体对照；当前是机制清单和样例。
  2. Item/得点/extend/rank/Bomb/符卡 bonus/捕获/掉落的原作精确内容策略及完整死亡/Deathbomb 流程。可配置规则和真实收集/得分/擦弹/miss/continue/Bomb 接线已加入，不等于策略已移植。
  3. 主/附属/死亡动画、Boss 演出/HUD 可配置控制；粒子通用 API 已加入，但原作粒子 ANM、 三维深度和附属动画仍未移植，不要求复制原作 VM。
  4. camera/fog/scene 时间编排，以及原作 GUI/时停视觉细节；分系统背景暂停/恢复已接线。
  5. 对全部发射模式、effect flags、ExIns 的正常内容样例和独立原作标量/时序/呈现验证。

6. 粒子专项边界（2026-10-13） ​

参考 src/EffectManager.cpp 的 20 类粒子：0–2/12 是爆发/停弹闪光，3–11 是随机散射和 恒定减速，17/18 是固定方向的 60/240 帧收拢，19 是给定速度/加速度的双翼颗粒。 这些运动和贴图帧/颜色/alpha/尺寸/旋转由 ParticleEffect 与公开 emit_particles 表达； 原作寿命/视觉来自 ANM，当前示例只验证独立机制，不声称新视觉时序等于 ANM。 13–15 可用整群 transform_particles 表达旋转轨迹的二维投影和 16 帧淡出/放大；示例为 一个 Task 的 NumPy Rodrigues 旋转，不建 48 个粒子回调，也未接原作轴向/radius 控制器 和三维深度。16 属于符卡背景演出，应继续走既有背景编排，不把背景塞进碰撞弹池。

维护者提供的 Steam 本地 th06c 中七个 .dat 魔数均为 PKGL；参考 checkout 的 PBG3 读取器不能直接使用。当前只读确认了格式，没有解码这些资源，也没有将游戏数据提交到 仓库。源代码开源不代表原作图像/音乐可再分发。通用粒子 API 的真实 GL 验证使用现有 引擎图集，游戏数据的本机抽取/动画时序对照仍是明确待办，不假报资源已复刻。
