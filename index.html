PySTG 文档 ​

Python + OpenGL 实现的东方 Project 风格弹幕射击游戏引擎。

引擎层提供高性能子弹池、激光、碰撞、渲染、音频； 内容层用 Python 协程编写关卡、波次、Boss 符卡； 两层通过 StageContext 桥接，互相解耦。

我是新手，从哪开始？ ​

  1. 先看 快速开始：装环境、跑游戏、了解项目布局。
  2. 再看 弹幕脚本开发指南：写第一张符卡。
  3. 想做杂兵就翻 敌人预设系统。
  4. 想用编辑器管理资产看 编辑器工具。
