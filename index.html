PySTGPython + OpenGL 弹幕射击游戏引擎

用 async/await 编写关卡脚本，用 ModernGL 与 Numba 驱动高密度弹幕，并配套编辑器、资产系统和 QQ 群弹幕互动。

项目简介
GitHub

高性能弹幕

基于 NumPy 结构化数组、Numba JIT 与 ModernGL 实例化渲染，面向海量子弹同屏的稳定运行。

协程化关卡脚本

使用 Python async/await 描述 Wave、Boss、符卡和非符，让时间轴、等待与并行动作更接近弹幕设计思路。

完整 STG 玩法

覆盖判定、擦弹、Power、Bomb、符卡、道具掉落、练习模式、Debug 跳转等核心体验。

数据驱动资产

纹理图集、精灵动画、弹幕别名、敌人预设和行为预设都可以通过 JSON 配置维护。

编辑器工具链

提供统一场景编辑器工作台、资源浏览器、弹幕别名管理、纹理资产、自机、敌人、背景、对话和 UI 布局工具。

QQ 群弹幕互动

内置 UDP 接入层，可通过 NoneBot、Mirai 等外部机器人把弹幕消息转化为实际游戏子弹。
