高性能弹幕运行时

基于 NumPy 结构化数组与 Numba JIT 批量更新，ModernGL 实例化绘制，支持批量行为阶段与分系统慢速。

协程关卡脚本

使用 async/await 自然表达波次、敌人、Boss 与符卡时序，无需繁琐回调。

完整 STG 玩法

判定点、擦弹、Power、Bomb、受击救援窗口、符卡、道具掉落、难度选择、练习模式与 Debug 跳转。

数据驱动资产

纹理图集、精灵动画、弹幕别名、敌人预设与行为预设均使用 JSON 配置。

关卡编辑器与资产工具

代码驱动关卡编辑器以声明式 Python 为唯一真源；纹理、自机、弹幕别名、立绘与背景提供独立可视化工具。

QQ 群弹幕互动

内置 UDP 监听服务，可对接 NoneBot、Mirai 等外部机器人把群消息实时转为游戏弹幕。
