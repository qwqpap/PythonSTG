PySTGPython + OpenGL 弹幕射击游戏引擎

用 async/await 编写关卡脚本，用 ModernGL 和 Numba 驱动弹幕，并配套关卡编辑器、资产工具和 QQ 群弹幕互动。

快速开始
架构概览
GitHub

弹幕运行时

子弹池基于 NumPy 结构化数组和 Numba 编译的更新逻辑，渲染使用 ModernGL 实例化绘制。

协程关卡脚本

用 async/await 描述波次、Boss、符卡和非符的时序，不需要回调。

STG 玩法

判定点、擦弹、Power、Bomb、符卡、道具掉落、练习模式和 Debug 跳转。

数据驱动资产

纹理图集、精灵动画、弹幕别名、敌人预设和行为预设都使用 JSON 配置。

编辑器工具链

代码驱动关卡编辑器以声明式 Python 为唯一真源；纹理、自机、敌人、背景、对话和 UI 使用独立工具编辑。

QQ 群弹幕互动

内置 UDP 接入层，可通过 NoneBot、Mirai 等外部机器人把群消息转换为游戏中的子弹。
