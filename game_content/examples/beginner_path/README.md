# PySTG 新手练习路线

这是一套可以直接用编辑器打开的作者资源，按文件名前的编号由易到难排列。
它既可以给第一次接触 PySTG 的人自学，也可以作为 N6.4 新手测试的统一入门资料。

> 这些是参考成品，不是 Python 脚本。正式测试时请从“新建弹幕”或关卡模板开始，
> 不要复制成品文件来代替任务。

## 1. 启动编辑器

在项目根目录打开 PowerShell：

```powershell
python tools/scene_editor.py --project .
```

进入编辑器后：

1. 在“语言”菜单选择“简体中文”。
2. 用“文件 → 打开资源…”打开本目录中的 `.pystg.json` 文件。
3. 按 `F6` 或选择“运行 / 预览”，始终使用正式预览观察结果。
4. `Ctrl+S` 保存，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。

如果是参加计时测试，请先阅读任务卡再开始计时；遇到困难时不要让观察员教你按钮位置，
把卡住的位置告诉观察员记录即可。

## 2. 由易到难的示例

| 难度 | 文件 | 重点 | 建议体验时间 |
| --- | --- | --- | --- |
| 1 | `01_first_pattern.pystg.json` | 环形弹幕、数量、速度、发射间隔 | 5–10 分钟 |
| 2 | `02_aimed_fan.pystg.json` | 自机狙扇形、每轮角度变化、速度变化 | 10–15 分钟 |
| 3 | `03_short_midstage.pystg.json` | 两波道中、时间线、全灭后继续 | 20–30 分钟 |
| 4 | `04_two_phase_boss.pystg.json` | 两阶段 Boss、背景转场、事件反应 | 30–60 分钟 |
| 配套 | `tutorial_background.pystg.json` | 关卡使用的三层背景 | 不单独计时 |

所有引用都使用 `res://game_content/examples/beginner_path/...`，移动整个项目目录不会破坏资源定位。

## 3. 练习 1：第一次修改弹幕

打开 `01_first_pattern.pystg.json`，先启动一次预览。然后只改三个值：

1. 把“数量”从 16 改为 24；
2. 把“速度”从 1.4 改为 2.0；
3. 把“发射间隔”从 24 帧改为 16 帧。

再次预览，确认弹幕更密、更快。随后撤销一次、重做一次，再保存。

完成标志：正式预览中能看到变化；撤销和重做都能恢复正确数值。

## 4. 练习 2：理解动态变化

打开 `02_aimed_fan.pystg.json`。它会朝玩家方向发射扇形弹，每一轮还会轻微转向和加速。

建议依次尝试：

1. 调整扇形角度范围；
2. 调整“每轮角度偏移”；
3. 调整“每轮速度偏移”；
4. 按“选择预设 → 调整参数 → 添加动态变化 → 编辑节点 → 查看脚本源码”的顺序浏览入口，
   但本练习不要求写脚本。

完成标志：能够解释“单轮形状”和“轮与轮之间的变化”分别由哪个参数控制。

## 5. 练习 3：两波短道中

打开 `03_short_midstage.pystg.json`，依次查看场景树、关卡流程和时间线。

这个示例包含：

```text
第一波（环形弹幕）
  └─ encounter.cleared 事件 → 第二波
第二波（追踪扇形）
  └─ encounter.cleared 事件 → 结束
结束
```

第一波和第二波分别引用前两个弹幕文件。时间线上的“敌人全灭后继续”是事件反应，
不是脚本。你可以先改变两波持续时间，再拖动移动片段，最后用撤销/重做确认改动可恢复。

完成标志：能指出两波内容、两条转移和两个弹幕资源分别在哪里编辑。

## 6. 练习 4：两阶段 Boss

打开 `04_two_phase_boss.pystg.json`。它包含完整的四段流程：

```text
登场（背景淡入、BGM）
  ↓
通常阶段（环形弹幕、Boss 横移、全灭事件）
  ↓
强化阶段（追踪扇形、背景转场、全灭事件）
  ↓
结束
```

再打开 `tutorial_background.pystg.json`，观察背景资源仍是独立、可编辑的作者文档。
尝试修改强化阶段的持续时间、背景淡入时间或第二阶段弹幕，再保存、重开并正式预览。

完成标志：两个阶段使用不同弹幕；强化阶段能触发背景转场；全灭事件能进入下一阶段；
保存重开后修改仍然存在。

## 7. 正式 N6.4 测试任务卡

参加正式测试时，观察员会提供干净的项目副本。三个任务都必须从新资源或模板开始，
可以阅读本指南和打开参考示例，但不能复制参考 JSON，也不能写脚本。

### 任务 A：首个 Pattern（目标 10 分钟）

新建一个 Pattern，选择一个预设，调整至少两个精确参数，并在正式预览中看到结果。

### 任务 B：两波短道中（目标 30 分钟）

使用“道中关卡模板”完成两波内容；两波使用可辨认的不同弹幕，并配置敌人全灭后继续。
保存、重开后再正式预览。

### 任务 C：两阶段 Boss（目标 60 分钟）

使用“两阶段 Boss 模板”完成两个阶段、一次背景转场和一次事件反应；至少进行一次撤销/重做，
并进入一次“编辑节点”后返回参数界面。最终保存、重开并正式预览，全程不写脚本。

## 8. 遇到问题时

- 先查看底部“输出”和“预览”面板中的错误位置；
- 确认资源路径以 `res://` 开头，没有指向项目外部；
- 确认当前打开的是你准备编辑的标签页；
- 正式测试中如果仍然卡住，停止盲目尝试并让观察员记录失败点；观察员不能现场带做。

观察员应另外阅读 [RESEARCHER_GUIDE.md](RESEARCHER_GUIDE.md)。
